# 영어 내신 문제은행 생성기 (Netlify MVP)

기출 시험지를 업로드하면 → 유형을 분석하고 → 시험범위·지침에 맞춰 예상문제를 생성해 → **문제지·답안지 Word(.docx)** 로 내려받는 웹앱입니다. 모든 선생님이 브라우저에서 사용합니다.

## 무엇이 필요한가
1. **Netlify 계정** (무료로 시작 가능)
2. **Anthropic API 키** — 생성 1회마다 소액 비용 발생. https://console.anthropic.com 에서 발급, 결제수단 등록 필요.

## 폴더 구조
```
netlify-app/
├─ index.html                  # 화면(입력 폼 + Word 생성)
├─ netlify.toml                # Netlify 설정
└─ netlify/functions/
   ├─ analyze.js               # 1단계: 기출+범위 분석 → 유형 프로파일
   └─ generate.js              # 2단계: 지침에 맞춰 문항 생성 (지침이 시스템 프롬프트로 내장됨)
```

## 배포 방법 (드래그 앤 드롭, 약 5분)
1. 이 `netlify-app` 폴더를 통째로 준비합니다.
2. https://app.netlify.com 에 로그인 → **Add new site → Deploy manually** (또는 https://app.netlify.com/drop) 로 폴더를 끌어다 놓습니다.
3. 배포 후 **Site configuration → Environment variables** 에서 키를 추가합니다:
   - `ANTHROPIC_API_KEY` = 발급받은 키
   - (선택) `MODEL` = `claude-sonnet-5` (기본값). 더 높은 품질은 `claude-opus-4-8`, 더 저렴·빠름은 `claude-haiku-4-5-20251001`.
4. 환경변수 저장 후 **Deploys → Trigger deploy → Deploy site** 로 재배포합니다.
5. 발급된 주소(예: `https://your-site.netlify.app`)를 선생님들과 공유합니다.

> Git으로 관리하려면 이 폴더를 GitHub 저장소로 올리고 Netlify에서 해당 repo를 연결하면 됩니다(자동 배포).

## 사용 흐름 (화면)
1. 기출 시험지 PDF/이미지 업로드 (스캔본 OK)
2. 학교 이름·학년 입력
3. 시험범위 업로드(본문·문법·의사소통·부교재) 또는 텍스트로 입력
4. 문항 수 선택(50/100) → **문제은행 생성하기**
5. 생성된 문제 상단에 **출제 범위**가 자동으로 적힙니다
6. **문제지 / 답안지** 를 각각 Word로 내려받기

## 동작 원리
- `analyze.js` 가 기출과 범위를 읽어 학교별 유형 프로파일(서술형 형식·함정·목표문법·본문·어휘)을 뽑습니다.
- `generate.js` 는 **우리 출제 지침(종합판 v2.0 + 품질기준)** 을 시스템 프롬프트로 넣고, 프로파일·범위를 근거로 섹션별 문항을 생성합니다.
- 브라우저가 결과를 모아 시험지형(2단) Word 문서를 만듭니다.

## 주의 · 한계 (MVP)
- **함수 실행시간**: 무료 플랜은 함수 10초 제한입니다. 100문항은 섹션별로 나눠 호출하지만, 느린 경우 50문항을 권장하거나 Netlify 유료(26초)로 올리세요.
- **비용**: 생성량에 비례해 API 비용이 듭니다. 대량 사용 전 소량으로 비용을 확인하세요.
- **품질 검수**: 생성 결과는 반드시 사람이 최종 검수하세요(정답 유일성·난이도·범위 적합성). 지침의 품질기준(§15)을 프롬프트에 넣었지만 100% 완벽은 아닙니다.
- **보안**: API 키는 서버(환경변수)에만 두고 화면에 노출하지 않습니다. 외부에 사이트를 공개하면 누구나 생성=비용이 나가므로, 필요하면 Netlify **Password protection**(유료) 또는 접근 제한을 거세요.

## 자주 겪는 문제
- `ANTHROPIC_API_KEY 환경변수가 설정되지 않았습니다` → 3~4단계(환경변수 추가 후 재배포) 확인.
- 생성이 도중에 멈춤 → 무료 플랜 10초 제한일 수 있음. 50문항으로 시도하거나 유료 플랜.
- 정답/문장 오류 → 모델을 `claude-opus-4-8` 로 바꿔 품질을 높이고, 사람 검수로 보완.
